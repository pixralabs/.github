## 🚀 What We're Building

### [zerocopy-ui](https://github.com/pixralabs/zerocopy-ui) (Coming Soon)
A server-driven UI framework that ships UI updates in **150 bytes**. No JSON parsing. No loading spinners. Built on FlatBuffers and Cloudflare Edge.
